### Doodle Scene Prompt:

```
DOODLE PROMPT: A simple line-art illustration showing two contrasting scenes side by side.

LEFT SIDE (chaos): A stressed stick figure surrounded by floating disconnected icons - a laptop, spreadsheet, phone, email envelope, calendar - all with tangled dotted lines between them going nowhere. Small scribble clouds indicating confusion.

RIGHT SIDE (calm): A relaxed stick figure with the same icons now neatly connected by clean flowing lines that form a simple pipeline. A small lightbulb or star above their head.

Style: Minimal black line doodle on white/cream background. Playful, hand-drawn feel. No color or very subtle single accent color (soft blue or green).
```

### White Circle Area (Top of Page) - Options:

**OPTION A: Animated Doodle Loop (RECOMMENDED)**
```
A simple looping animation of the chaos-to-calm transformation:
- Frame 1: Tangled lines connecting scattered icons
- Frame 2-3: Lines slowly untangling
- Frame 4: Clean, organized flow
- Loop smoothly

Tool: Use Lottie animation (free Lottie files available) or create in After Effects/Rive
```

**OPTION B: Static Doodle Illustration**
```
The chaos-to-calm split image described above, but formatted to fit a circle.
Simple and clean - no animation needed.
```

**OPTION C: Short Video Loop (5-10 seconds)**
```
A hand-drawn style animation showing:
- Messy desk/workflow transforming into organized system
- Or: A simple "before/after" morph

Keep it subtle, no sound, auto-loop.
```

**OPTION D: Interactive Element**
```
A slider that visitors can drag:
- Left = chaos visual
- Right = calm visual
- They control the transformation

Creates engagement and demonstrates the value visually.
```

**OPTION E: Quiz Score Preview**
```
A simple animated gauge/meter that cycles through different "scores"
with labels like "Foundation Critical" → "Almost Ready" → "AI Ready"

Teases the quiz result they could get.
```

**MY RECOMMENDATION:**
Option A (Animated doodle loop) or Option D (Interactive slider) - both reinforce the core message visually and feel "easy" which matches Aasani's meaning.

## DOODLE STYLE GUIDE (For Consistency)

**Overall Style:**
```
- Black line art on white/cream background
- Hand-drawn, slightly imperfect lines (not too polished)
- Stick figures for people (simple, expressive)
- Minimal detail - suggest rather than show everything
- Single accent color optional (soft blue, green, or warm yellow)
- Playful but professional - not childish, not corporate
- Consistent line weight throughout
```

**What to Avoid:**
```
- Overly detailed illustrations
- Multiple colors
- 3D effects or gradients
- Stock photo style
- Clip art look
- Robotic/cold AI imagery
```

**Mood:**
```
- Calm
- Approachable
- Human
- Slightly whimsical
- Trustworthy
```

## TECHNICAL NOTES FOR FRAMER

**Spacing:**
- Generous whitespace between sections
- Let the page breathe
- Mobile: stack columns vertically

**Scroll Behavior:**
- Smooth scroll to sections from nav
- Consider subtle fade-in animations on scroll

**CTA Buttons:**
- Primary: Solid fill, high contrast
- Secondary: Outline or text link
- Make buttons large enough for mobile taps

**Quiz Integration:**
- Embed Typeform or link to Typeform page
- Or use Tally (free) embedded form

**Calendly Integration:**
- Embed or link to Calendly scheduling page
- For "Book a Call" buttons
