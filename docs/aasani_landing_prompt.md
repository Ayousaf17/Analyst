# Aasani.ai Landing Page – Google AI Studio Prompt

## Purpose
Generate a high-fidelity landing page concept for Aasani.ai that reflects the brand's "systems-first AI reliability" positioning and follows the structure and messaging pillars defined in the single-page guide and website blueprint.

## Visual & Interaction Style
- Full-width hero with clean, confident typography and balanced white space.
- Glassmorphism dashboard module in hero to visualize before/after clarity.
- Icon-based value cards with hover lift and subtle shadow micro-interactions.
- Slim stat strip with key metrics.
- Testimonial block, process/timeline steps, pricing/contact band, and multi-column footer.
- Soft neutral base (porcelain, dove gray) with a single accent (soft blue/teal) for CTAs and highlights; maintain high contrast for accessibility.
- Typography: modern sans-serif with clear hierarchy; ensure legible sizes and sufficient line height.
- Micro-interactions: smooth hover lift on cards, gentle shadows on buttons/cards, focus states with visible outlines.

## Layout Order (Top → Bottom)
1. Sticky nav (logo, anchor links, primary CTA).
2. Hero (headline/subhead, dual CTAs: **Book a Demo** primary, **Download Brief** secondary, plus glassmorphism dashboard visual).
3. Stat strip (3 quick metrics aligned to reliability/uptime/data quality).
4. Value pillars (cards for **People First**, **Clean Data**, **Connected Tools**; include iconography and short support lines).
5. Timeline/process (4 steps: Assess, Design, Build, Improve with short descriptors).
6. Feature detail band (optional supporting image or dashboard slice).
7. Testimonial/proof (quote + name/title placeholder).
8. CTA band (book demo + download brief, restating reliability promise).
9. Pricing/contact band (simple plan summary or "talk to us" line).
10. Footer columns (links, contact, social, small print).

## Brand Voice & Messaging Anchors
- Tone: calm, direct, and confident—"boring" systems-first rigor that makes AI work on Monday morning.
- Hero headline anchor: "Stop Building AI on Broken Foundations" with a subhead about fixing workflows, data, and tools so AI actually works.
- Value pillars mirror the blueprint: **People First** (workflow and change support), **Clean Data**, **Connected Tools**. Emphasize reliability over hype.
- Include a single supporting stat option: "85% of AI projects fail because of broken foundations" to reinforce the reliability claim.

## Copy Placeholders
- Hero headline placeholder + subhead reinforcing systems-first reliability.
- Primary CTA label: **Book a Demo**. Secondary CTA label: **Download Brief**.
- Three value pillars: titles + one-sentence descriptors.
- Stat strip: three short stats (e.g., uptime %, data accuracy %, cycle time reduction %).
- Testimonial: quote, name, role placeholder.
- Process steps: Assess, Design, Build, Improve—each with one short sentence.
- Pricing/contact band: brief plan teaser + CTA to book a call/demo.

## Accessibility
- Ensure color contrast meets WCAG AA for text and controls; avoid low-opacity overlays that reduce legibility.
- Minimum body text 16px with clear hierarchy; provide focus states for all interactive elements.
- Use descriptive alt text for visuals (dashboard, icons) and ensure CTA labels are descriptive.

## Output Requirements
- Provide structured HTML/CSS-ready copy and component notes in order above.
- Keep the layout clear, scannable, and light on jargon.
- Make the hero/dashboard visual feel like a clean systems view (inputs → clean data → reliable AI outputs) to echo the before/after story.
