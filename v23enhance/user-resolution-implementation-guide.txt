📋 OVERVIEW

This system adds intelligent user resolution to your Gorgias Terminal, enabling
natural language queries like:
  ✅ "show me collin's tickets"
  ✅ "assign to @collin" (Slack mention)
  ✅ "bailey's urgent stuff" (nickname/last name)
  ✅ "gabe's billing issues"

BEFORE: 50% accuracy (GPT guesses emails)
AFTER:  95% accuracy (database lookup)

 PHASE 2: SLACK ID SYNC (30 minutes)
═══════════════════════════════════════════════════════════════════════════

OPTION A: Automated Sync (Recommended)
───────────────────────────────────────
File: /mnt/user-data/outputs/slack-sync-workflow.js

1. Create new n8n workflow "Slack User ID Sync"
2. Add nodes as documented in file:
   - Manual Trigger (or Schedule Trigger)
   - Slack: Get Users
   - Code: Format Slack Data
   - Supabase: Fetch Gorgias Users
   - Code: Match & Update
   - Code: Supabase Bulk Update
   - Slack: Send Notification

3. Configure Slack API credentials:
   - Create Slack App: https://api.slack.com/apps
   - Add OAuth Scopes: users:read, users:read.email
   - Install to workspace
   - Copy OAuth token to n8n credentials

4. Run workflow manually first time
5. Check Slack notification for results
6. Verify in database:
   SELECT COUNT(*) FROM gorgias_users WHERE slack_user_id IS NOT NULL;
   -- Should return: 13 (all human users)

OPTION B: Manual Entry (Quick Start)
─────────────────────────────────────
If you already know Slack user IDs:

UPDATE gorgias_users 
SET slack_user_id = 'U12345ABC', 
    slack_display_name = 'ayub'
WHERE email = 'ay17yousaf@gmail.com';

-- Repeat for each user...

To find Slack user IDs:
1. In Slack, click user profile
2. Click "More" → "Copy member ID"
3. Paste into UPDATE statement above

 PHASE 5: MONITORING & MAINTENANCE
═══════════════════════════════════════════════════════════════════════════

DAILY MONITORING
────────────────
Check user resolution success rate:

SELECT 
  DATE(created_at) as date,
  COUNT(*) as total_queries,
  COUNT(CASE WHEN extra->>'users_found' > '0' THEN 1 END) as resolved,
  ROUND(
    COUNT(CASE WHEN extra->>'users_found' > '0' THEN 1 END) * 100.0 / COUNT(*),
    1
  ) as resolution_rate
FROM agent_sessions
WHERE created_at > NOW() - INTERVAL '7 days'
  AND extra ? 'users_found'
GROUP BY DATE(created_at)
ORDER BY date DESC;

Target: 95%+ resolution rate

WEEKLY MAINTENANCE
──────────────────

TROUBLESHOOTING
───────────────
Issue: User not resolving
Solution:
1. Check if in database:
   SELECT * FROM gorgias_users WHERE LOWER(first_name) = 'username';
2. Check if name pattern matches:
   SELECT * FROM find_user_by_name('username');
3. Add nickname if needed:
   UPDATE gorgias_users SET nickname = 'username' WHERE email = '...';

Issue: Wrong email returned
Solution:
1. Check for duplicates:
   SELECT * FROM gorgias_users WHERE LOWER(first_name) = 'username';
2. If ambiguous (e.g., two Roberts), use full name or last name
3. Update priority in find_user_by_name() function

Issue: Slack mentions not working
Solution:
1. Verify Slack IDs populated:
   SELECT email, slack_user_id FROM gorgias_users WHERE slack_user_id IS NULL;
2. Run Slack sync workflow
3. Check Parse Slack extracts mentioned_users correctly
